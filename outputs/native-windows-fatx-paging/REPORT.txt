0051 replaces the shortcut with file-relative translation through a resident
cluster map. The chain is read when the paging file is opened or resized.
Paging I/O coalesces adjacent clusters and splits fragmented runs without
consulting the cached FAT. Invalid ranges fail before disk access. Growth
publishes a new immutable map; old maps remain until FCB destruction so
outstanding I/O cannot use freed map memory. Published files cannot shrink.
The map costs4bytes per cluster plus12bytes per version (24KiB for96MiB
at16KiB clusters). Repeated successful growth retains old map memory until
close, a deliberate lifetime tradeoff requiring longer endurance testing.
Lower I/O reuses VFAT's existing partial-MDL request/completion path.
