# Using the new E installation

From UnleashX's file explorer, launch:

    E:\Applications\XWNEBoot\default.xbe

Keep the Razer keyboard unplugged through Xromwell; connect it after Windows
appears. This starts the E copy with the1080i boot/display chain. Inside Windows,
`C:\WINNT` and `C:\Documents and Settings` belong to **dashboard E**. The copy
has normal startup restored, so it will stay at the desktop rather than rerun
the automated test. Use Windows Start → Shut Down → Restart to return to the
dashboard when finished.

The existing root-level **Windows** menu still starts the original F installation.
Its launcher is:

    E:\Applications\XWNFBoot\default.xbe

That installation and its registry hives were preserved and rechecked. The
dashboard C menu/configuration was not edited. Do not interchange the two
launchers or their loader files: each profile targets a different partition.

The new E copy passed its boot, drawing, audio API, shutdown and integrity
checks, and has about2.07GB free. Overall qualification still fails on the
existing Ftdisk49 and dashboard-C capacity warning. This is a private E-install
preview; it does not replace or retag the immutable0.2.0 release. Current source
package and verified pre-boot recovery files are private at `E:/xwn337/package001`
on the development PC, with manifests under `outputs/stock-physical337`.
