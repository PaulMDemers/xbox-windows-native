# Fresh Xbox assembly from the customized SP4 installation

The fresh assembly passes its functional emulator scope. It boots from the
dashboard into Windows at 1280x720x32, persists exact file bytes, passes the
offscreen GDI check, exposes one wave device with successful playback completion,
and transfers 131,072 independently verified bytes in each TCP direction. The
final boot has no automatic diagnostic startup; its witness was invoked through
the ordinary Run dialog, then requested normal Windows restart. Host exit was
orderly, without timeout or fallback kill.

**Strict qualification remains false.** Eight source paths were excluded by the
offline FATX writer. Ftdisk 49 remains, final emu006 also records kbdhid 1, and
the previous installation boot records seven PlugPlayManager 256 warnings.
The inherited typed DRM DataPath decoder failure remains. None is waived.
This is not physical installation, public-installer, whole-Windows-feature,
performance, stereo-listening or release qualification.
