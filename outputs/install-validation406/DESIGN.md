# 406: separate name, hive, event and application evidence

The native FATX format has a counted 42-byte field. The current driver converts
through the installed OEM tables and rejects larger names. Actual405 SYSTEM
selects OEM437. The two half-character shortcuts are encodable as byte AB;
the remaining six paths contain genuinely oversized components. This work
does not introduce a long-name alias scheme, modify a crypto identity or relax
the original transfer gate.

The read-only public name preflight uses strict reversible CP437 conversion,
rejects absolute/relative traversal, invalid/control characters and oversize
components. All6475 original manifest paths are checked. Native406 independently
copies the two original179-byte shortcuts through CopyFileW, tries a43-byte
name, and queries the opaque DRM value through RegQueryValueEx. No settings,
services, registry values or driver binaries are modified by the helper.

The same helper launches the actual installed mplayer2.exe with a private
MPEG-1/MP2 derivative and waits for its process to complete. This alone is NOT
playback proof. Separately captured frames are matched against independently
decoded source frames, and the complete captured AC97 speech envelope is
compared with the source and reversed/shuffled negative controls. No copyrighted
video, PCM, Windows files or private credentials enter the source repository.

The case is a continuation of the closed/audited405 installation, not another
fresh-from-ISO claim. A new flattened full-disk copy on E was compared against
405. Preparation002 then refused an already-existing XWN406/probe.exe before
writing. Complete virtual-disk comparison proved that failed preparation still
equaled its source. Preparation003 uses that NEVER-BOOTED identical seed and
an unused XWN409 directory. It adds exactly three files, checks every other
file unchanged, and retains normal Startup. The runtime gets a new private
overlay/EEPROM, one launch, an owned lease and a600-second outer bound. Only
ordinary UI input is used; screenshot geometry is an explicit720p assumption.

Cold collection checks every file, all allocation, five hive headers and two
raw-value readers, event history/deltas, all15 protected fresh403 paths, media
bytes and the restored shortcuts. Historical405 verdicts are never rewritten.

## Long-name work still required

A generic installer cannot simply substitute a shorter SID, hash an RSA key
filename or shorten a COM+ log. Windows requests these exact components and may
enumerate them. A future storage solution must define reversible logical names,
collision/case rules, enumeration, rename/replace/delete and directory lifetime,
crash persistence and interoperability with the Xbox dashboard's native FATX
reader/writer. A sidecar index without native filesystem support is not a fix;
unused/deleted directory slots are not safe long-name storage because other
writers can reuse them. FATX field-size changes would be an incompatible format.
No such implementation is installed here. Lossless provisioning must currently
refuse these six paths rather than discard security/application state.
