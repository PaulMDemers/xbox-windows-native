# Manual-launch comparison

Use a fresh namespace and the same qualified sample/controller behavior, with
the same original boot path. Change the host adapter to perform baseline and
payload readback checks, record the manual request, and send no launch command.
The user opens the exact File Explorer path once. Record their observation
separately; a request receipt is not proof of actual execution.

All sample, independent descriptor, normal restart, cold audit and cleanup gates
remain unchanged. A return without results does not qualify or fail D3D. Capture
the failed attempt, remove its hook and close it rather than retrying until PASS.
