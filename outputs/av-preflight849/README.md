# 849 read-only kernel AV prerequisite diagnostic

Separate nxdk kernel diagnostic, based on the report writer in 690. It reads kernel AV settings, reported physical pages, SMC cable byte, EEPROM video byte 0x96 and the encoder's register-zero response using kernel SMBus calls. It creates a fresh `E:/xwn-av849-NN.json`, flushes it, checks exact readback and requests firmware reboot. It never writes EEPROM or video settings, programs a video mode, launches 633 or changes the functional boot bundle. The encoder response is not a chip identifier; kernel-context values do not prove what the native launcher observes later. A completed report confirms this diagnostic executed; it does not prove 633 dispatch, guard outcome, or transaction stage.

Build under the shared build lease with `build.py`; the candidate and build log remain private. `host001.json` records 8192 compiled expression cases and static writer checks. No emulator or physical launch has been performed. Kernel SMBus, filesystem and firmware calls are not application-timeout bounded; automatic reboot occurs after those calls return. Failed report creation/flush/readback is not reported as success; a partial exclusive file may remain. The 100-name create-new sequence never overwrites a report.
