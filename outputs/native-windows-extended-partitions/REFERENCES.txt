The disk-image driver intentionally sets the virtual partition StartingOffset
to the physical disk end. This exactly matches the observed C query. The
installed softmod version has not been identified; source agreement does not
prove that this exact revision is installed.

PARTINFO has a 16-byte magic, 32 reserved bytes, and fourteen 32-byte entries
starting at byte 48. Entries contain a 16-byte name, flags (in-use bit
0x80000000), 32-bit start LBA, 32-bit sector count and a reserved word.
Unknown extensions and gaps in active partition numbering are rejected as
unsupported by this initial implementation.
