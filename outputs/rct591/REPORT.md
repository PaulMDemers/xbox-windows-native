One ordinary Windows launch was accepted at 23:30:52 UTC after the user confirmed
a full power-off and return to UnleashX. The dashboard was reachable at the first
bounded observation, 23:31:30. No repeat launch was sent.

The helper produced no result directory and no new save file. All selected
Windows files, including the collected event logs, were byte-identical before
and after. There were no new system/application records and no additional
EventLog 6006 shutdown record. This does not locate the boot failure; it provides
no evidence that Windows or the save helper completed. The screen observation
is pending and must not be inferred from FTP availability.

The owned startup entry was removed before collecting 28 files. All five system
hives and the user hive passed the independent audit. The game registry subtree,
Welcome preference and executable, ordinary launcher, startup and protected
720p configuration were preserved. The inventory still contains 502 game files.
Only selected game payloads were read back after execution; this is not a whole
FATX allocation audit. Historical Ftdisk49 limitations remain.

The physical experiment is closed as unsuccessful/incomplete. Phase 2 was not
admitted or launched. Both unchanged PC-qualified helpers remain available, but
their PC result does not establish an Xbox result. No graphics/performance claim.
All owned host processes are closed; the console was at the dashboard at final
collection. Game assets remain at `/E/xwn586-kit/game`; no test startup hook remains.
