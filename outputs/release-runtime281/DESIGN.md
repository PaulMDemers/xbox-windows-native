# Actual adapter boundaries

Read release-worker280/DESIGN.md and unbound-release279/DESIGN.md for the retained
worker and counted-release contracts. All277/279 helper and280 worker inputs are
frozen with renderer001; legacy zero-callback admission is not weakened.

The renderer provider follows successful x280_capture with renderer/PG locks
retained, checks x277 proof, live cache/unit edges, current worker/native render
context and an acquire-published closed-frontend UI capture. The GL query closure
is deliberately scoped to the pinned GL4.0 interfaces and known containers.
Unknown extensions/objects are not declared retired. UI capture acquisition has
the inherited outer watchdog limitation; the new provider introduces no UI job.

control281 and candidate281 allocate all three ledgers before publication. The
PFIFO worker consumes each initial/end request once. Pre/post graphs, scalar
records and snapshot data are available only after overall state3,5 or6. Stage3
cannot be read at state3. Accepted end request changes state to4; initial immutable
records survive the terminal publication. A selected page cursor is monitor-owned
and never used as worker state. Old finish/seal/capture operations refuse on this
transaction. No previous one-shot actor is reset.

Each capture requires acknowledged CPU-exclusive inventories, stable mutation
clock within the pair, live callback-to-surface bijection, fences and exact actual
contexts. Pre/post retained graph equality permits only the declared four unit
edges/refcounts/dirty bits in candidate mode. Post-release snapshots are one-shot,
preserve GL pack/PBO/selection state through the original observer and join any
failure into273's transport error union. Actual normal guest binds alone set their
reserved lifecycle records and capture mask.

Do not infer success from one slot, a sealed file, empty work queue or pb_busy.
Independent complete reports, paired graph linkage, actual source/key/RGBA and
framebuffer pixels, exact terminal273 accounting, cleanup and cold audit remain
mandatory. A failure after mutation is quarantined without rollback or resume.
