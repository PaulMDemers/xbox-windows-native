The existing calibration assembly temporarily unmasks RTC IRQ8 and the
slave cascade, installs its RTC handler at vector 38, programs RTC registers
A/B, ignores the first interrupt and measures the loop count until the
second. It derives StallScaleFactor, disables the RTC periodic interrupt,
and restores the RTC IDT entry, PIC masks and prior flags before returning.
This changes RTC operational registers as part of normal HAL startup; it
does not restore their previous register A/B values or set calendar time.

The diagnostic saves the RTC IDT words and table base before calibration.
The final callback requires the validated preceding checkpoint sequence,
expected native caller and loader block, active paging and matching CR3,
a positive bounded stall factor, exact RTC IDT restoration, PIC mask ffff
and IF restored. It then disables interrupts and halts. The stall factor
is machine-dependent; the emulator's value is not a hardware target.

Yellow XWNT40 means base HAL setup passed and RTC calibration is starting.

wait if no RTC interrupt arrives; there is no automatic timeout or dashboard
return. If yellow remains after 15 seconds, photograph it and reboot.
