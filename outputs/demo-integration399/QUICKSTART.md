# Xbox Windows2000 demo —720p

For the configured console, no archive extraction is needed.

1. Connect the mouse before booting. Keep the Razer keyboard unplugged through Xromwell.
2. At UnleashX choose **Windows**. Direct fallback: `E:\Applications\XWNEBoot\default.xbe`.
3. Connect the keyboard after Windows appears. Close Welcome and known unsupported-device prompts without disabling devices.
4. Use720p: the user confirmed clean text and full-window dragging.1080i remains diagnostic.
5. Try Notepad, Paint, Calculator, Solitaire, Pinball and audio. Save a note/BMP under `C:\xwndemo372`, close it, then reopen it.
6. Use **Start → Shut Down → Restart** to return to UnleashX normally. There is no timed test shutdown.

Choose `C:\xwndemo372\Full window dragging.cmd` or `Outline dragging.cmd`.
`Display status.cmd` reports the setting. Changes persist for the current user;
the existing one-time outline initializer does not override a saved preference.
