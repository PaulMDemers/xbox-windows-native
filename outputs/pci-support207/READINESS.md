# Deployment status: NOT READY

This branch is experimental source and evidence. There is no approved physical
package. The original console and all shared baseline files remain untouched.

The only implemented function is exact MCPX SMBus ID
`PCI\VEN_10DE&DEV_01B4&SUBSYS_00000000&REV_B1`. It exposes read-only AV-pack and
temperature telemetry. It does not supply modem, audio, USB, EEPROM, encoder or
power-control support. Restricting the API does not settle shared-bus concurrency
with other future drivers; the coordinator must review that ownership explicitly.

Completed prerequisites: physical identification and typed resource inventory,
actual HAL reboot-port analysis, 67,617 transaction-engine adversaries, 2,954
requirements-filter adversaries, two paused model runs including missing-chip
recovery, NT5 x86 compilation and 61 verified import/dynamic export resolutions.
Native001 also completed actual Windows installation and live telemetry. Its
independent cold audit passed integrity/history checks, and installed destination
hashes match the built driver/INF. It was host-stopped, so normal shutdown and
persistence remain unqualified. None of these establishes physical safety.

Native002 retained the exact working binding across one cold relaunch without
reinstalling and passed fresh telemetry plus cold integrity. Its normal restart
guard held on actual pending installation258. New SetupAPI identifies unresolved
audio01B0, with no new SMBus installation. It sent no dialog action and made no
restart request. Completion of supported setup in other workstreams is required
before the two normal-shutdown cycles can qualify. No blanket cancellation or
dummy binding is proposed as a substitute.

Promotion requires actual completed installation, exact selected INF/service/
class linkage, assigned C000 resource, successful live telemetry with expected
forbidden-request errors, no PnP problem, two consecutive ordinary persisted boots
without owner-prompt cancellation or host restaging, normal shutdown and independent
cold integrity/history checks. Power/lifecycle/security enforcement remain open.
The inherited Ftdisk49 remains a strict whole-boot failure even if telemetry works.

01C1 cannot be qualified in the present xemu model: PCI function6.1 is absent.
A coordinator must first collect physical read-only modem codec/resource evidence
and resolve AC'97 link/reset ownership with the audio workstream. No null binding,
disabled device or substitute emulated identity would establish functionality.

Before a later physical candidate, the coordinator must capture fresh original
SYSTEM/SetupAPI/events and affected files, hash readbacks and rollback copies,
verify original storage/display/network/input baselines and startup restoration,
then stage only a reviewed exact-ID package. Expected evidence must include live
resources, typed binding and telemetry, shutdown and subsequent cold readback.
The final installation/rollback protocol must be tailored to the actual emulator
result and reviewed package; this document authorizes no physical deployment.
