# Xbox Windows 2000 demo preview

This package combines experimental analog stereo PCM audio (ACI207 build004)
with the tested RAM-backed software display118 and shared-framebuffer158 chain.
It is an overlay/validation package for the owned installation, not Windows media,
a complete installer, or a generally qualified release. Immutable0.1.0 is separate.

The physical253 audit and narrow binding-transition review preserve its original
binding-equality failure; six inactive ACI values copied preexisting active values.
A subsequent255 boot passed original exact equality with zero binding changes.
These bounded results exercise six audio phases,
five drawing samples, normal restart and cold integrity checks. The known
boot-time Ftdisk49 crash-dump configuration error remains a strict failure. Audio
API completion does not prove perceived sound quality or left/right routing.
The user heard the login sound but no255 test tones. Audible test-channel validation
is unresolved; diagnostic256 is separate and does not change these binaries.

## Demo sequence

1. Leave the Razer keyboard unplugged through Xromwell. Select Windows from the
   UnleashX root menu. Connect keyboard/mouse after the Windows boot handoff.
2. If unsupported-device wizards appear, cancel them without disabling devices.
   Audio is genuinely installed; the APU/PCI/gamepad support is not completed.
3. Open Notepad, Calculator and Paint. Draw, save to the Windows drive, close and
   reopen the file. Show window movement without calling it GPU acceleration.
4. Play an existing Windows sound to demonstrate analog PCM. The tested format
   is48kHz/16-bit stereo. Digital audio, capture and mixer controls are unqualified.
5. Use Windows Start → Shut Down → Restart. Do not power-cycle during writes.

The software display reduces redundant text uploads in the measured cases.
That is not a desktop-frame-rate measurement. GPU acceleration,1080i and other
new modes are unfinished; USB gamepad functionality is not part of this preview.

## Reassemble exact inputs

After the recorded253 supplemental review and255 unchanged-binding scoped audit
and both accepted-state readbacks, run:

```text
python outputs/demo-package254/assemble.py --output /private/new/demo-preview.zip
```

The output must not already exist. Every selected binary is hash-checked; entries,
metadata and ordering are fixed. Assemble twice to verify identical ZIP hashes.
This reproduces packaging, not compiler output. Source recipes live under
audio207 (ACI004), video-text-clip205 (display118), video-shared-framebuffer
(miniport/bootvid) and demo-integration251 (joined validation runner). Historical
one-shot build scripts must be adapted to fresh isolated outputs before reuse.

The general reconstruction tool under outputs/reproducible-build covers the
older base components. A single portable command that rebuilds the complete
current installation remains unfinished. Do not present this overlay as that.
