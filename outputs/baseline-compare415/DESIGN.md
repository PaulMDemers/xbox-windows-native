# Comparison scope

Use live read-only E capture versus the closed normal-restarted406 installation.
Protect evidence with original file/disk hashes and exclusive output IDs. Do not
boot or parent the closed406 runtime. Capture code, loader configuration and
selected registry state privately; commit only scripts and compact findings.

PE classification allows only three explicit metadata fields and requires exact
length/layout and every other byte. XBE classification validates independent
length-prefixed SHA1 section digests and exact known wrapper/Cromwell code
ranges; date strings alone cannot authorize changed code. Negative mutations
must reject a digest-valid altered code image.

Linear disassembly cannot separate all executable-section data from code.
Keep unclassified spans explicit. Registry defaults are not live video-mode
measurements. No comparison result authorizes an automatic policy change.

The physical baseline and fresh installation are different test populations.
Keep route, starting state, installed version and observed stage distinct.
Do not label the failure intermittent without matched repeated evidence.
