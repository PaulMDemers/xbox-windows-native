# Windows 2000 media inspection

Inspection recorded 2 October 2026. Both user-supplied ISOs were read without mounting or executing their contents. Original images were left unchanged. Selected files were extracted into the task's working directory for inspection; embedded product-key values were redacted from extracted text and excluded from this report.

**Use `EN_WIN2000_PRO_SP4.ISO` as the initial native-loader baseline.** Retain `Windows 2000 (SP4).iso` as a secondary, customized comparison image. No further Windows ISO is needed for the first development stages.

The linked image's unattended file includes a prefilled `ProductID` and fully unattended installation settings. This explains why installation is expected to skip manual key entry; it is not evidence that the installer has no key requirement internally. Setup has not been run, so actual installation behavior remains unverified.

The linked ISO's size and SHA-1 match the Internet Archive item's published file metadata. This verifies correspondence with that upload, not authenticity as an unmodified Microsoft release. The uploader labels it as requiring no product key. [Supplied archive item](https://archive.org/details/windows-2000-sp-4), [file metadata](https://archive.org/metadata/windows-2000-sp-4).

The customized ISO also has a different kernel and many additional setup hotfix files. Its `CDROMSP5.TST` filename is recorded as a customization marker, not proof of an official Microsoft SP5 release. These differences introduce extra variables when debugging kernel/HAL compatibility, which is why the smaller image is the preferred first baseline.

Both PRODSPEC.INI files retain older inventory fields, including `ServicePackNumber=0`. Those fields alone are not a reliable service-pack determination for these images. The SP4 marker and extracted binary versions provide additional evidence. The smaller ISO has not been authenticated against an independently trusted original-disc hash; it is a candidate baseline based on the inspected contents, not a certification that every file is stock.

## Development consequence

The media prerequisite is satisfied for the source audit and Windows 2000 loader work. Pin the smaller ISO and its extracted kernel/HAL as the initial comparison set. Next, audit the FreeLoader handoff contract against these exact binaries and construct the diagnostic bootstrap. Preparing an installed system-volume fixture remains separate work: neither an ISO nor a directory of extracted binaries supplies a complete installed registry and boot-volume configuration.
