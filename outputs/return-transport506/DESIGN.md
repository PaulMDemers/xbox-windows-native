# Separate transport reachability from file-content proof

A forwarded FTP control port does not forward arbitrary passive data ports.
Observe returned dashboard with authenticated control conversation and exact
112byte receipt size, retaining full stage/reply/error. No PASV/PORT/RETR and no
implicit fallback. A separate cold comparison must verify all112receiptbytes
against actual guest memory and checked record decoder, plus protectedfiles and
full disk audit. Neither half independently qualifies the complete contract.

This is a NEW return-observation contract, not retroactive acceptance of505's
failed live-transfer contract. Actual kernel APIs/entry guards/cleanup remain
unchanged. Host servers/probe callbacks are explicit models; actual stdlib socket
transport and waiter logic execute. No firmware/kernel/driver workaround added.
