# Separate desktop callback diagnostic

Prerequisite: strict ordinary video-desktop-lifecycle/candidate001 passed.
Use identical compiled probe126 and RAM0109 driver, same immutable prepared
parent, fresh unique child. Never reuse the ordinary runtime disk. No rebuild,
physical access, registry or driver edits. Inherited emulator device policy stays.

Arm before launch. Discover the actual kernel with two IDT gates and owned binary
identity. Pin the actual helper at entry and every desktop marker. Across each
create-through-close interval observe DrvEnablePDEV, DrvCompletePDEV,
DrvEnableSurface, DrvDisableSurface, DrvDisablePDEV, DrvAssertMode,
XwnRegisterPrimary, XwnUnregisterPrimary and XwnOwnershipDisable. Use our actual
owned COFF symbol addresses; no guessed Win32k internals. Pair calls by thread,
return PC and exact stack displacement, with resident relocated byte checks when
called. A function merely armed is not evidence it executed or was resident.

At fifteen ordered API markers preserve all32 ownership slots and each occupied
PDEV's seven owner/surface/shadow fields. Permit and record actual owner changes;
do not equate successful desktop deletion with driver surface deletion. This
observer holds the module base constant; a reload at another base is an explicit
unsupported observer case/failure, never an invisible waiver.

Bound600 seconds/384 stops/64 driver calls; remove every breakpoint and resume in
finally. On observer failure preserve it and permit normal guest completion, never
retry the same child. Run all ordinary cold/event/hive/allocation/image/pagefile
gates independently after closure. Debugger-assisted results are never ordinary or
physical qualification. No complete display-text residency claim is made.
