# Two-stop observation design

Exact510 keeps its original file/LED body and adds an entry JMP at11100. The511
observer adds actual stops at11100 and94aff, compares eight GPRs includingESP,
EFLAGS and CR0/3/4, and guards old preparation at11105. It retains507 actual API,
page-walk, immutable captures,506 bounded control-only dashboard return and cold
content validation. No guest register or memory writes are authorized.

trampoline.py is the actual adapter compiled into the host tests by import.
The original507 observer and helpers reconstruct after explicit source substitutions.
The entry header check was wrong: disk encoding and loaded representation are
separate contracts. Actual511 capture now supplies that distinction; a new
observer must validate each representation explicitly, not allow either value
indiscriminately. No candidate binary correction is justified by this refusal.
