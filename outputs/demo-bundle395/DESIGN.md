This kit is prepared while physical394 is running. Preparation is not a PASS
or authorization to bypass its result. No archive or accepted-state record
exists until the corresponding one-shot script succeeds.

Acceptance requires physical394's complete command and direct API persistence,
720p drawing, audio API, normal shutdown and cold integrity gates. Collection
first restores normal startup and original FATX0101. The post-scan final-state
record must independently confirm that restored state. The known Ftdisk49
strict failure remains visible; scoped demo acceptance is not a strict release.

The acceptance script rechecks every final-state file before changing only
dashboard E's xwnfatx.sys to the exact tested390 bytes. It then reads back all
protected files and hives. A failed update attempts original0101 restoration;
any failed rollback is recorded explicitly. It never boots, changes video or
audio, accesses dashboard C, or replaces the original F installation.

its original0101 rollback, source references and instructions. The private
system archive reconstructs the hash-pinned343 E payload with376 controls,

fresh backup, a public installer or a tested full restore. Existing archives
and tags remain immutable. Both outputs go to C:/xwn395 on the development PC;
this host path is unrelated to the Xbox dashboard C partition.
