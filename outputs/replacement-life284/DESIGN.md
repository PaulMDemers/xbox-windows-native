# Proposed adapter contract; not installed

The serialized core is not thread-safe and does not authorize an operation. Its
caller supplies the real acknowledged renderer worker, four independently attested
old keys/identities/names and complete graph/context/CPU proof. Owner IDs supplied
by the host test are models. Positive owner values in the binary must be matched
to actual runtime attestation; the standalone decoder does not establish that.

Use a new one-shot observer and owner transaction. Do not reset old246/247/265/273
actors or relax273's same-live-generation schema. Initial arm requires actual
refs2/cache1/unit1. Control performs the already qualified unit release then real
normal rebind; candidate additionally disposes the four cache owners before
guest resume. Both retain all unrelated resources and dirty surfaces/callbacks.

Required instrumentation on exact281 source:

1. Save only scalar identity, GL name and old refcount before the original
   texture_binding_destroy body; record its completed decrement AFTER that body.
   The saved final refs1 event means the original free returned, not merely the
   existing pre-decrement x269 hook. Do not read the freed object. Complete actual
   namespace deletion/error checks and cache-node absence remain separate gates.
2. Record replacement creation at the actual normal binder generate_texture
   return, using current live cache node, exact zero-initialized TextureKey and
   freshly returned binding. A new pointer alone is not creation evidence. All
   old final-free events must precede any birth. Allocation/name recycling assigns
   a new generation, never revives a tombstone.
3. Record normal guest-driven binds only through the pinned original binder. A
   replacement must first have an observed birth and then actual refcount2. No
   host binder call, fabricated event, cache scalar patch or data substitution.
4. Snapshot actual source/palette/RGBA at initial, post-unit, post-disposal and
   post-replacement boundaries as applicable. Follow only a freshly found live
   cache edge before reading a binding. Independent owned source/framebuffer
   oracle remains unchanged; recorded keys/hashes alone are not pixel evidence.

Publication must close entry and account for any in-flight writer using a proven
one-word gate, then seal on the original acknowledged worker and release-publish
the immutable terminal. Closed gate alone is not completion of terminal writes.
Getters require acquired final publication; timeouts preserve metadata, never
free/rearm. Union core, gate, snapshot and transport errors; failed publication
is one-shot and cannot produce a replacement successful file. Existing269 gate
is a source lead only until the actual new wrapper and concurrency tests exist.

The four-boundary actual worker still needs implementation: pre-unit, post-unit,
post-disposal BEFORE resume, then post-replacement. Each has fresh CPU-exclusive
acknowledgments and complete locked context/owner/graph checks. Third candidate
state contains absent old cache owners, not fake refcounts or fake zero callbacks.
Keep whole4096byte source/guard blocks disjoint, mutation clocks stable within
transactions, and use complete acquire-published UI/container evidence. A partial
mutation or GL/snapshot/publication failure quarantines; no rollback or resume.

This is narrow ownership disposal, not a renderer shutdown, complete backend
retirement, native Windows PTE/cache-alias resolution or GPU handoff.
