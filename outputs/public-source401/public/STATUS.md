# Evidence scope

The current private 720p demo uses software display303, HD300 components,
E334/E720p374 boot chain, audio004 and the FATX390 cached-directory-index fix.
Storage390 was installed with readback verification after its physical test;
the integrated demo's normal startup and original rollback were retained.

The original398 auditor used the previous driver's expected hash and reported
failure. That report was preserved. Separate corrected analysis verified the
tested390 bytes and changed only the three hash-dependent workload verdicts;
it did not waive Ftdisk49 or the strict release gate. Earlier failed and interrupted
tests remain in the private evidence archive, outside this public-source candidate.

This is not an accelerated desktop. Recent matched software-copy/stretch tests
showed no material improvement. Emulator ownership experiments, GPU retirement
models and standalone graphics tests do not establish native Windows GPU control.
PCI/gamepad prototypes are excluded from the demo. Synthetic emulator policy and
the physical console's actual devices are different environments.
