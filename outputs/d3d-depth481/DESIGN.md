# Matched Xbox depth comparison design

Build/deploy gated on the completed fresh PC480 control and exact sample hash.
Same original depth sample, five fixed RGB capture oracles, default and HEL in
separate processes. The controller alone changes source-copy path and namespace.
No desktop mode change, driver change, Xbox dashboard C access, global settings,
or unattended dialog actions. At most16 files in the owned result namespace.

Namespace-only471 boot wrapper retains original Windows payload byte-for-byte,
symbols and wrapper size. Real assembled wrapper tested against modeled kernel
I/O; actual dispatcher tested against modeled FTP. These are host tests, not
physical results. Unique481 boot/result/kit paths, one20-second SITE request,
480-second outer observer, two90-second process deadlines. Never retry accepted
or uncertain launch. On return remove the temporary hook first, collect all
results twice, audit five hives/events and verify original launcher/startup/720p.
Actual module bytes and PE image sizes must match the PC comparison. Preserve
Ftdisk49, popup events, boot failures and incomplete evidence independently of
scoped rendering success. No full FATX allocation audit is claimed here.
