# Corrected outline-drag utility

The original372 exact-token parser rejected trailing whitespace left by cmd
redirection. This separate source accepts only trailing spaces/tabs after a
recognized mode and still rejects extra words, prefixes, wrong case and newline.
Twelve checks execute the extracted function under ASan/UBSan. The NT5 build is
7ff648f3e41cff123ca6659482e94a2575ec8a081ffbfbbd2387e97e605ac470.

The unchanged setting path uses SystemParametersInfo with profile persistence
and broadcast, verifies the live value and HKCU DragFullWindows, and offers
outline/full/status plus a restoring selftest. Actual runtime qualification is
recorded in377; compilation/host parser tests alone do not qualify deployment.

The private add-on package contains only this original utility, command files
and guides. Its runtime folder remains C:\xwndemo372 for a stable user-facing
path. It is not a Windows image, full recovery or driver upgrade.
